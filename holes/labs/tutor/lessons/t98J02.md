# Lesson 2: t98J02, lifted curves

**Problem.** `F` is a closed surface, `p : E → F` a finite cover, `C` a simple closed curve and
`L` a lift of it, so `p` carries `L` homeomorphically onto `C`.  (a) If `C` does not separate,
must `L` not separate?  (b) If `C` separates, must `L`?

Try before reading on: the torus and a double cover of it.

## Part (a): count something

The informal solution says an embedded circle separates exactly when its mod 2 homology class
vanishes, and pushes the class down by `p`.  That is a sound classical proof.  In Lean it needs
surface collars and duality, and the blueprint priced it at 1500–3500 lines.

Ask a smaller question.  Suppose `E \ L` falls into open pieces `P` and `Q`.  For `x` in `F`,
let `a(x)` be the number of points of the fibre over `x` lying in `P`.

1. Off `C`, no fibre point lies on `L`, so each sits in `P` or `Q` and stays there as `x` moves.
   So `a` is locally constant off `C`, and constant because `F \ C` is connected.  Finiteness
   of the cover makes `a` a number.  An infinite cover has no such count, and part (a) is false
   for one: the circle `S¹ × {0}` in the cylinder `S¹ × ℝ`, which covers a torus.
2. Over a point of `C`, the fibre has one point on `L` and the others off it.  Near there every
   sheet but one stays on one side.  So if the remaining sheet had points in `P` and in `Q`,
   then `a` would change by one.  It cannot, so near each point of `L` the sheet lies on one side.
3. "Which side" is locally constant along `L`, and `L` is connected, so it is one side all the
   way round, say `P`.  Then `P ∪ L` is open.  `Q` is open too, so `E` is disconnected unless `Q`
   is empty.

## Moves

- **Replace a global invariant by a count.**  Homology answered a yes-or-no question; a count that
  is locally constant answers it with less.  Lesson 1 did the same with the zero count `N(w)`.
- **Say where the hypothesis acts.**  Connected `E` is used only at the last line, finite only in
  step 1, nonseparating only for "constant".  If a hypothesis has no job, suspect the proof.
- **Check a wild curve.**  The argument never asks what `C` looks like near a point, so it does
  not care if `C` is fractal.  One small fact remains: `C` contains no open patch of `F`, or step 3
  could not tell the sides apart.  Antipodal values on a small circle give it: a map from a circle
  to the line agrees at some pair of antipodes, so a patch cannot inject into a line.

## Part (b): pick the small example

The blueprint proposed genus two, and priced the quotient charts at 350–700 lines.  A closed
surface is any closed surface, so try a smaller one.  Quotient the torus by the free involution
`(u, v) ↦ (-u, -v̄)`: this is a Klein bottle.  `Im v` is invariant, so it descends to a continuous
function, and it vanishes exactly on the image `C` of the circle `v = 1`.  So `C` separates.
Upstairs, `v = 1` is a coordinate circle, whose complement is connected.

**Move: a counterexample only needs one model, so choose the one with a function on it.**

## What the star map saw

t98J02 carries four tags: Jordan curve and simple closed curves, fundamental group, and surfaces,
all at the weak passing tier, and connectedness at the Lean tier.  Only connectedness names what the
proof uses, and none of them suggests the count.  As with lesson 1, the skills name tools and the
moves above carry the reason.

## Exercises

1. Step 1 fails for the cylinder covering a torus.  Which fibre has no count?
2. The disconnected reading fails: where in the argument does the trivial double cover escape?
3. Prove a circle in the plane has empty interior using only the intermediate value theorem.
4. In part (b), what does `Im v` become on the two Möbius bands?
5. Every separating circle on a torus bounds a disc.  Why does this make (b) true for torus base?
