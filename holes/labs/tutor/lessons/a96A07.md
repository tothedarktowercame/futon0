# Lesson 1: a96A07, one-to-one on the boundary

**Problem.** `g` is analytic near the closed unit disk `Δ̄` and one-to-one on the unit circle `Γ`.
Show `g` maps `Δ` one-to-one onto the bounded domain `D` whose boundary is `C = g(Γ)`.

## 1. Try to break it

Before planning, test the statement on small cases.

- `g(z) = z²` fails the hypothesis, since `±z` collide on `Γ`.  It also fails the conclusion: it is
  2-to-1 on `Δ`.  So boundary behaviour and interior behaviour may be tied together.
- `g(z) = (1+z)²` satisfies the hypothesis.  The curve is a cardioid, in polar form
  `r = 2 + 2cos θ`.  Here `g'(-1) = 0`, a critical point **on** `Γ`.  So `C` need not be smooth, and
  any argument that assumes a smooth curve is wrong.  This one example rules out a family of proofs.

**Move: find the example that kills the tempting simplification.**

## 2. Turn the question into a number

"One-to-one" and "onto" are both claims about how many times `g` takes a value.  So define

`N(w)` = number of solutions of `g(z) = w` in `Δ`, with multiplicity, for `w ∉ C`.

The theorem becomes: `N = 1` on one region and `N = 0` elsewhere.  `N` is computed by an integral,

`N(w) = (1/2πi) ∮_Γ g'(z) / (g(z) - w) dz`,

so it is an integer that depends continuously on `w`.  That gives the fact everything rests on:
`N` is constant on each connected piece of the complement of `C`.

**Move: replace a counting question by an integer-valued continuous function.**

## 3. The textbook finish, and three repairs

The usual route says `N(w)` is the winding number of `C` about `w`, and the Jordan curve theorem
gives winding number `±1` inside and `0` outside.

The informal solution in the repo follows this and has three faults worth noticing.

1. Its Step 2 claims `g(Δ) ⊆ D` from connectedness.  That does not follow: nothing yet stops `g(Δ)`
   from crossing `C`.  This fact should come last, not first.
2. Its Step 3 gets the sign from "analytic maps preserve orientation".  The clean reason is that
   `N ≥ 0`, because it is a count.  So `±1` can only be `+1`.
3. Its Step 4 discusses multiplicity through nearby values.  That is unnecessary: `N` already counts
   multiplicity, so `N = 1` means one simple preimage.

**Move: when a sign is in doubt, look for positivity.**

## 4. The Jordan theorem is the wrong size

Mathlib has no Jordan curve theorem, no winding number and no Brouwer theorem.  The earlier blueprint
called this problem blocked for that reason.  The better question is how much of Jordan is used.

We use: `N ≤ 1`.  That is all.  Injectivity follows, because two preimages of a value could be
perturbed to two preimages of a value off `C` (`C` has area zero), giving `N ≥ 2`.  The rest of the
statement follows from injectivity and the open mapping theorem, with `D = g(Δ)`.  We do not need to
know the inside of `C` is connected, or that `C` is the boundary of the outside.

**Move: before importing a big theorem, write down the one consequence you actually use.**

## 5. Getting `N ≤ 1` directly

Four facts suffice.

- `N` is constant on components (section 2).
- `N = 0` far from the disk's image, so `N ≠ 0` only on bounded components.
- `C` has at most one bounded component.
- Somewhere `N` jumps by exactly one.

Then the values of `N` lie in `{0, m}`, and include `R` and `R + 1`.  So `R = 0` and `m = 1`.

**The jump.**  Pick `ξ ∈ Γ` with `g'(ξ) ≠ 0`, and factor
`g(z) - g(ζ) = (z - ζ) F_ζ(z)`, where `F_ζ` is the difference quotient.  For `ζ` near `ξ`, Rouché
says `F_ζ` has the same number of zeros in `Δ` as `F_ξ`, call it `b`.  The factor `z - ζ` adds one
zero exactly when `ζ` is inside the disk.  So `N(g(ζ))` is `b + 1` for `ζ` inside and `b` for `ζ`
outside.  No picture of a curve having two sides is needed.

**At most one bounded component.**  This is the only topology, and the argument is short.
A logarithm of `z - a` on a compact set `K` is an obstruction test:

> Borsuk's criterion.  If `a` is in a bounded component of the complement of `K`, then `z - a` has no
> continuous logarithm on `K`.

Proof idea: extend the logarithm over the plane, patch it with `z - a` to get a nonvanishing function
on a big disk, take its logarithm, and restrict to the bounding circle, where `z - a` winds once.

Cut `C` into two arcs.  On an arc every nonvanishing function has a logarithm, since an arc is an
interval in disguise.  For two points `a₁, a₂` in different bounded components, the logarithms of
`z - aᵢ` on the two arcs agree at one join and differ by `2πi mᵢ` at the other.  Then
`(z - a₁)^{m₂} (z - a₂)^{-m₁}` has a logarithm on all of `C`, because the mismatches cancel.  The
criterion forces `m₁ = m₂ = 0`, so `z - a₁` itself has a logarithm on `C`, which contradicts it.

**Move: two integers that each obstruct can be combined so that their obstructions cancel.**
