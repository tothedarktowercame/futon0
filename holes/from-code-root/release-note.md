# Futon Stack — Preliminary Release Candidate (Stack-wide)

## Futon0

Futon0 establishes operational awareness by turning existing activity traces into low-friction vitality signals and a stable review cadence. Prototype 0 anchors early warning in Tatami sessions, git activity, filesystem timestamps, and recording cadence, while Prototype 1 adds a weekly epistemic rhythm (AOB/Ambitions sync, Org as canonical plan, bounded WIP) so salients reappear on schedule without extra logging.

Prototype 0 fixes the ingest → NLP → graph-memory → XTDB pipeline as a baseline contract, and Prototype 1 turns the demo/client workflow into instrumentation that emits stable focus headers and comparable outputs for regression detection.
