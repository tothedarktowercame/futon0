# Weekly Coherence Scan

Purpose: run a lightweight weekly sweep that keeps devmaps, stack status,
workflow cadence, and library canon aligned.

When: once per week (pick a fixed day/time).

## Inputs
- devmaps in holes/
- top-level READMEs for each futon
- futon3 pattern store + library ledgers
- recent git activity and test artifacts
- futon1 or Tatami logs for rhythm checks

## Weekly checklist
1) Workflow cadence
- weekly-rhythm (AOB + Ambitions within 7 days)
- wip-cap (<= 3 active focus areas)
- sphere-equilibrium (touch all five spheres)

2) Devmap coherence
- devmap-scope-discipline
- next-steps-to-done
- IFR sweep (f1..f7) and IFR-state-convergence
- prototype alignment (bridge, role, tension, embedding)

3) Stack coherence
- readme-devmap-sync
- evidence-ledger
- ready-blocked-triage
- stack-blocker-detection
- staleness-scan
- commit-intent-alignment
- futon1-determinism (only if futon1 touched)

4) Library coherence
- library-template-discipline
- library-evidence-ledger
- library-readme-sync
- library-staleness-scan
- library-embedding-refresh
- pattern-differentiation-alarms

## Output artifacts
- mismatch reports (readme/devmap/pattern store)
- status changes (done/ready/blocked/drift)
- evidence links captured in ledgers
- notes on blockers and next steps

## Notes
- Prefer marking drift quickly and scheduling fixes over trying to resolve
  everything inside the weekly sweep.
- If new patterns are added, remember to refresh embeddings and update ledgers.
