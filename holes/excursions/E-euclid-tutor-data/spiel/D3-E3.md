# DESIGN-3 E3: budgeted best-first prover

Date: 2026-11-12. The trained and generation-0 arms are **ZERO**. I.1,
I.3, and I.2-from-givens use no Book proof, prefix, or move hint. The I.2
stage-2 rows use the **DEMO prefix, ZERO search**: the prefix chooses the
start state, but neither the search nor scorer receives a proof move.

## Protocol

Each opened node receives one scorer call. Candidates are sorted once and
offered in pages of ten. The best-first cost is accumulated negative log
softmax probability; later pages include the cost of their best move.
Guarded admission is authoritative, children are checked immediately using
the game's own goal test, and exact logical states are deduplicated. Each arm
has 400 opened-node calls, ten wall minutes, and the game's move cap.

The trained scorer is E2b's final ZERO model. Generation 0 uses the same
architecture and seed `2026111202`. Random scores are i.i.d. uniform with
seeds `2026111203`, `2026111204`, and `2026111205`. Five arms ran in parallel
per problem, with problems sequential, in one 24 GiB/1,024-task scope. The
twenty receipts completed in 37m10s; the scope exited normally.

## Proofs and fresh replay

Every reported proof was replayed from a fresh copy of its stated start;
all nine replays reached the game goal.

I.1 trained:

1. `circle_from_points(a,b) [C=C_1]`
2. `circle_from_points(b,a) [C=C_2]`
3. `intersection_circles(C_1,C_2) [c=c_3]`

I.1 generation 0 and random 1205 reverse the first two circle moves and use
`intersection_circles(C_1,C_2)`. Random 1203 does the same but uses
`intersection_circles(C_2,C_1)`. Random 1204 uses the trained arm's circle
order and `intersection_circles(C_2,C_1)`. All five fresh replays are **yes**.

I.2 stage 2, generation 0 and random 1204:

1. `circle_from_points(d_2,g_6) [C=C_1]`
2. `intersection_circle_line_extending_points(C_1,L_3,a,d_2) [g=g_2]`

I.2 stage 2, random 1203:

1. `off_line_strict_triangle(b,a,d_2,L_3)`
2. `superposition(b,c,b,a,d_2,b,BC,BC,BC,L_3) [AC'=AC'_2 BC'=BC'_2 b'=b'_2 c'=c'_2]`

I.2 stage 2, random 1205:

1. `off_line_strict_triangle(a,b,d_2,L_4)`
2. `superposition(b,c,c,a,b,g_6,BC,BC,BC,L_1) [AC'=AC'_2 BC'=BC'_2 b'=b'_2 c'=c'_2]`

All four stage-2 fresh replays are **yes**.
