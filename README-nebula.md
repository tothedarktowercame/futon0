# Nebula: where stars might form

Written 2026-10-10 (from `holes/missions/M-landscape-positioning.md` §4.2).

The capability star map (`holes/missions/M-capability-star-map.*`) holds only
capabilities that a mission has minted. So a goal that has no mission yet does
not appear on it at all. This file holds those goals: **real effort with no
star yet**. Joe, 2026-10-10: most of them "*should* have a mission and star
associated, but maybe right now they are more like fodder for a nebula b/c they
are a bit nebulous and stars might form there."

Nothing here is a commitment. An entry leaves the nebula when a mission opens
for it, which is how stars form. Edit freely. Add entries when effort shows up
somewhere and no star covers it.
